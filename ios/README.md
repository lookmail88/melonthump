# MelonThump iOS app

Native SwiftUI app (iOS 17+, Swift 6, bundle id `dev.xuyang.melonthump`).
It records a watermelon tap and analyses it **entirely on-device** —
recordings are never uploaded. The server is only asked for the client
version policy at launch.

原生 SwiftUI App（iOS 17+、Swift 6、bundle id `dev.xuyang.melonthump`）。
录下拍瓜声后**完全在本地分析**——录音永不上传。服务端只在启动时被问
一次版本策略。

## How it works 工作方式

- **Recording 录音** (`AudioRecorder`): 5-second countdown, then
  auto-stop; the audio session runs in `.measurement` mode (AGC off) so
  levels stay truthful.
- 5 秒倒计时后自动停；音频会话用 `.measurement` 模式（关 AGC），保证
  电平真实。
- **Analysis 分析** (`LocalAnalyzer`, heuristic-v2.2): time-domain +
  spectral thump gates reject non-thump sounds as `UNKNOWN`; a real thump
  is judged by its dominant resonant frequency (< 160 Hz OVERRIPE /
  160–280 Hz RIPE / > 280 Hz UNRIPE — placeholder thresholds, calibration
  in progress).
- 时域 + 频谱双门控把非拍击声判为 `UNKNOWN`；真拍击按主共振频率判定
  （< 160 Hz 过熟 / 160–280 Hz 熟 / > 280 Hz 生——占位阈值，校准中）。
- **Launch gate 启动门** (`VersionGate`): the version policy is fetched
  during the 3-second launch screen; a client below the latest version
  gets a full-screen, non-dismissible update prompt. Failing to fetch the
  policy never blocks the app (fail-open).
- 3 秒启动页内拉取版本策略；低于最新版的客户端被全屏、不可关闭地提示
  更新。拉不到策略永不拦截（fail-open）。
- **Backends 后端**: an in-app Prod/Dev selector, Prod by default
  (`melonthump.stephaniegao.me` / `melonthump-dev.stephaniegao.me`).
- 应用内 Prod/Dev 选择器，默认 Prod。

## Ads & credits 广告与 credit

- Google Mobile Ads SDK 13.11 + UMP consent (via SPM): consent → ATT →
  SDK start → rewarded preload. A credit is granted only on the
  watched-to-completion callback.
- Google Mobile Ads SDK 13.11 + UMP 同意（SPM 集成）：同意 → ATT →
  SDK 启动 → 激励广告预载。只有看完回调才发 credit。
- `CreditWallet` is a **local** wallet in v1: an analysis costs 1 credit
  (`UNKNOWN` is free), a completed ad earns the policy's `creditPerAd`,
  new installs get a 5-credit welcome grant, daily earnings are capped
  at 10. A server ledger is a later phase.
- `CreditWallet` 在 v1 是**本地**钱包：分析扣 1（`UNKNOWN` 不扣）、
  看完广告按策略 `creditPerAd` 得、新装欢迎赠 5、每日得币上限 10。
  服务端账本是后续阶段。
- **Launch promo 推广模式**: while the server policy carries a promo
  window, credits are bypassed — the first thump of each fresh launch
  costs one rewarded ad, the rest of the session is unlimited; relaunch
  and you watch again. A -1 free day overrides the promo gate.
- 服务端策略带推广期时 credit 经济暂停——每次新开 App 第一次拍瓜看
  一支广告、本次打开内无限用，退出重开重新看。免费日（-1）优先于
  推广门。
- If a rewarded ad fails to load, AdsManager logs the error and retries
  with Google's official test unit (shipped behaviour since commit
  1495531).
- 激励广告加载失败时，AdsManager 记录错误并改用 Google 官方测试单元
  重载（commit 1495531 起的定版行为）。

## AdMob IDs & secrets 敏感 ID

Real AdMob IDs **never enter this public repository**. `Config.xcconfig`
carries Google's official test IDs; the real App ID / ad unit ID live in
a gitignored `Secrets.xcconfig` next to it on the build machine (start
from `Secrets.xcconfig.example`). Until the app is live on the App Store,
the official test IDs are used; the real IDs are switched in only for
the store build.

真实 AdMob ID **永不进这个 public 仓库**。`Config.xcconfig` 只带 Google
官方测试 ID；真实 App ID 与广告单元 ID 放在构建机上同目录、被 gitignore
的 `Secrets.xcconfig`（从 `Secrets.xcconfig.example` 起步）。正式上架前
一律用官方测试 ID；进 App Store 后才为商店构建切换真实 ID。
