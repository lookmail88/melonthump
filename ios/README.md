# MelonThump iOS app

SwiftUI, iOS 17+, Swift 6. Records a watermelon tap as WAV, uploads it to the
server's `/api/v1/tap/analyze` endpoint, and shows the verdict card.

## Build

Open `MelonThump.xcodeproj` in Xcode 16+ and press Run (iPhone simulator or a
real device). The project file is generated by `gen_pbxproj.py`
(`SDKROOT=iphoneos`, Swift 6, iOS 17 deployment target).

To regenerate after adding files:

```bash
cd ios
python3 gen_pbxproj.py   # then update SWIFT_FILES in the script first
```

## Notes

- The server URL is editable in the app. The simulator can reach the Mac's
  `http://localhost:8080`; a real device needs the Mac's LAN IP
  (e.g. `http://192.168.1.x:8080`).
- `Info.plist` allows plain-HTTP **local networking only**
  (`NSAllowsLocalNetworking`) for dev. Production will use HTTPS.
- UI text is English for now; final copy follows Stephanie's design elements.
- UI is intentionally simple/placeholder — Stephanie provides the design.
